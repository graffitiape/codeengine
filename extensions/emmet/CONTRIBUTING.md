## How to build and run from source?

Read the basics about extension authoring from [Extending Code Engine](https://github.com/graffitiape/codeengine/docs/extensions/overview)

- Read [Build and Run Code Engine from Source](https://github.com/graffitiape/codeengine/wiki/How-to-Contribute#build-and-run-from-source) to get a local dev set up running for Code Engine
- Open the `extensions/emmet` folder in the vscode repo in Code Engine
- Press F5 to start debugging

## Running tests

Tests for Emmet extension are run as integration tests as part of Code Engine.

- Read [Build and Run Code Engine from Source](https://github.com/graffitiape/codeengine/wiki/How-to-Contribute#build-and-run-from-source) to get a local dev set up running for Code Engine
- Run `./scripts/test-integration.sh` to run all the integrations tests that include the Emmet tests.
